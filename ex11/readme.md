# 과제 11: 삽입 정렬과 쉘 정렬의 성능 비교

삽입 정렬, 쉘 정렬(기본 간격 `n/2, n/4, …, 1`), 쉘 정렬(Knuth 간격 `1, 4, 13, 40, …`)의 **데이터 값 비교 횟수**를 측정하고 비교했습니다.

- 소스: `ShellCompare.c` / 실행 로그: `result11.txt`
- 빌드·실행: `gcc -O2 -o ShellCompare ShellCompare.c && ./ShellCompare`

## 1. 실험 방법
- n = 1,000 / 2,000 / 4,000 / 8,000 / 16,000 / 20,000, 값은 0~1,000,000 무작위 정수(Windows의 `rand()`는 최대 32767이라 두 번 호출해 30비트 난수로 만듦).
- 각 크기에서 원본 데이터를 1개 만들고 **동일한 복사본**을 세 알고리즘에 제공. 배열 복사·데이터 생성은 측정 제외.
- 비교 횟수: `a[j] > cur` 같은 데이터 값 비교를 결과와 관계없이 1회로 계산(반복문 인덱스 검사는 제외).
- Knuth 수열: `h = 1; h = 3h + 1`을 반복해 **n보다 작은 가장 큰 값**을 찾아 역순(`h /= 3`)으로 적용, 마지막은 h = 1.
- 모든 실행에서 ① 오름차순 여부 ② 원본과 같은 원소 집합인지 확인했고 **전부 통과**했습니다.
- 본 실험(과제 출력)은 크기당 1회이므로 난수 편차를 확인하기 위해, 같은 프로그램에서 **20회 반복 평균**도 보조로 구했습니다(분석은 두 결과가 일치하는 경향을 근거로 함).

## 3. 분석

### 3.1 데이터 크기 증가에 따른 변화
- **삽입 정렬**은 n이 2배가 될 때마다 비교 횟수가 거의 정확히 **4배**(3.98~4.01)가 됩니다. 즉 O(n²)입니다. 값도 이론 평균 `n²/4`와 일치합니다(n=1,000 → 약 25만, n=20,000 → 약 1억).
- **쉘 정렬**은 2배당 증가 배율이 **약 2.3~2.4배**입니다. 2.4 = 2^1.26 이므로 이 실험 범위에서는 대략 `n^1.2~1.3` 수준으로 증가합니다. 삽입 정렬의 n² 증가보다 훨씬 완만합니다.

### 3.2 삽입 정렬과 쉘 정렬의 성능 차이와 그 원인
- 차이는 n이 클수록 커집니다. n=1,000에서는 약 17배(245,918 vs 14,551)지만 n=20,000에서는 **약 160~185배**(1억 vs 62만/54만)입니다. 증가 배율이 4배 대 2.4배로 다르기 때문에 격차가 계속 벌어집니다.
- 원인: 삽입 정렬은 원소를 **한 칸씩** 옮기므로, 제자리에서 멀리 떨어진 원소는 그 거리만큼 비교·이동이 필요합니다(무작위 데이터의 평균 역전 수 약 n²/4가 곧 비교 횟수). 쉘 정렬은 큰 간격에서 먼저 정렬해 원소를 **먼 거리까지 한 번에** 이동시켜 역전을 크게 줄입니다. 간격이 줄어드는 뒷단계에서는 배열이 이미 "대충 정렬된 상태"라서, 삽입 정렬이 가장 빠른 입력(거의 정렬된 데이터)을 받게 되어 비교가 적게 듭니다.

### 3.3 기본 간격과 Knuth 수열의 차이
- 모든 크기에서 **Knuth가 기본 간격보다 적은 비교**를 사용했습니다(본 실험 6개 크기 모두, 20회 평균에서도 동일). 차이는 n=1,000에서 약 8%, n=8,000~20,000에서 약 13~17%로 n이 커질수록 약간 커지는 경향입니다. 이는 증가 배율에도 나타납니다(기본 ×2.37~2.41, Knuth ×2.29~2.40).
- 다만 차이는 삽입 정렬과의 차이(수십~백 배)에 비하면 **작습니다**. 무작위 데이터에서는 기본 간격도 충분히 잘 동작했기 때문입니다.

### 3.4 간격 수열이 성능에 영향을 주는 이유
1. **패스 수**: n = 20,000에서 기본 간격은 14단계(`10000, 5000, 2500, 1250, 625, 312, 156, 78, 39, 19, 9, 4, 2, 1`), Knuth는 9단계(`9841, 3280, 1093, 364, 121, 40, 13, 4, 1`)입니다. 각 패스는 최소한 약 n번의 비교를 하므로, 단계가 적은 Knuth가 유리합니다. 기본 간격은 줄이는 속도(÷2)가 느려 불필요하게 많은 패스를 돕니다.
2. **간격 사이의 약수 관계**: 기본 간격은 `…, 312, 156, 78, …, 4, 2, 1`처럼 **짝수가 연속**해서 서로 배수 관계입니다. 간격 2로 정렬한 뒤 간격 1로 정렬하면, 앞 단계에서 이미 확인한 같은 쌍을 다시 비교하는 경우가 많아 앞 단계의 효과가 뒤 단계로 충분히 섞이지 않습니다. Knuth 수열(`3h+1`)은 인접한 간격이 서로소에 가깝고 모두 홀수라 서로 다른 부분 배열의 원소를 더 잘 섞어, 앞 단계의 정렬 효과가 중복되지 않습니다.
3. **이론적 차이(참고)**: 기본 간격(2의 거듭제곱 계열)은 최악의 경우 O(n²)이 될 수 있는 반면 Knuth 수열은 최악 O(n^1.5)로 알려져 있습니다. 이번 실험은 **무작위 데이터**만 사용했으므로 이 최악 차이까지는 드러나지 않았고, 평균적인 성능 차이만 관찰했습니다. 이것은 실험으로 확인한 사실이 아니라 알려진 이론이라는 점을 구분해 둡니다.

## 4. 결론
삽입 정렬은 n²로, 쉘 정렬은 약 n^1.2~1.3 정도로 증가하여 n=20,000에서 쉘 정렬이 비교 횟수를 약 0.5~0.6%까지 줄였습니다. 같은 쉘 정렬이라도 간격 수열에 따라 성능이 달라져, Knuth 수열이 기본 간격보다 모든 크기에서 적은 비교를 사용했고 데이터가 클수록 이점이 조금씩 커졌습니다. 이는 간격 수열이 "패스 수"와 "각 패스가 앞 단계의 정렬 효과를 얼마나 잘 활용하는가"를 결정하기 때문입니다.

## 5. 한계
- 본 실험은 크기당 1회 측정이고, 보조 20회 평균으로 경향을 확인했지만 통계적 검정은 하지 않았습니다.
- 무작위 데이터만 사용해 간격 수열의 최악 입력 특성은 직접 측정하지 않았습니다.
- 이동 횟수·실행 시간은 과제 범위가 아니어서 측정하지 않았습니다.
